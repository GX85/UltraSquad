# UltraSquad в облаке (24/7, доступ с телефона)

Чтобы отряд работал, когда ноутбук выключен, сервер надо поднять на облачном хостинге.
Проект уже готов: есть `Dockerfile` и удалённый режим с токеном.

## Что понадобится от тебя
- Аккаунт на хостинге, который умеет держать **постоянный процесс** (не serverless). Подходят **Render**, **Railway**, **Fly.io**. Vercel НЕ подходит (там нет постоянного процесса, SSE и камеры).
- Готовность платить (обычно от ~$5/мес за инстанс, который не засыпает; у камеры-браузера аппетит к памяти — бери план с ≥1 ГБ RAM).
- Ключ OpenRouter и придуманный **REMOTE_TOKEN** (длинная случайная строка — это твой пароль входа).

## Render (проще всего)
1. Зайди на render.com → **New → Web Service** → подключи репозиторий `GX85/UltraSquad`.
2. **Runtime: Docker** (Render сам возьмёт `Dockerfile`).
3. Instance type: минимум **512 МБ**, лучше **1 ГБ** (для камеры).
4. В **Environment** добавь переменные:
   - `OPENROUTER_API_KEY` = твой ключ
   - `ALLOW_REMOTE` = `1`
   - `REMOTE_TOKEN` = длинная случайная строка (твой пароль)
   - (необязательно) `OLLAMA_URL`, `OLLAMA_API_KEY`
   - `PORT` Render задаёт сам — трогать не надо.
5. Deploy. Через пару минут получишь адрес вида `https://ultrasquad.onrender.com`.
6. Открой `https://<твой-адрес>/?token=ТВОЙ_ТОКЕН` — токен запомнится в cookie.

## Управление с телефона через приложение Claude
В `claude_desktop_config.json` (или мобильный MCP-коннектор, когда доступен) укажи адрес:
```json
{ "mcpServers": { "ultrasquad": { "command": "node",
  "args": ["путь/к/mcp/ultrasquad-mcp.mjs"],
  "env": { "ULTRASQUAD_URL": "https://ultrasquad.onrender.com", "X_TOKEN": "ТВОЙ_ТОКЕН" } } } }
```
(MCP-сервер шлёт токен; локально он не нужен.)

## Важно и честно
- **Безопасность.** Защита удалённого доступа — один токен поверх HTTPS хостинга. Для личного дашборда нормально, но это не банковский уровень: не давай токен никому, держи его длинным.
- **Ключи уедут в облако** — они будут в переменных хостинга (не в коде, не в git).
- **Камера** в облаке работает через Chromium в контейнере; на маленьком инстансе может тормозить — тогда переключись на «Текст» в эфире.
- **Реальные атаки.** Как только сервер публичный, его начнут сканировать боты из интернета — и ловушки/бан/карантин заработают по-настоящему, не на имитации.
- Это твой сервер и твой трафик; отвечаешь за него ты.

## Локально ничего не меняется
Без `ALLOW_REMOTE` сервер по-прежнему слушает только `127.0.0.1` и токен не спрашивает.
