# UltraSquad

UltraSquad — локальная консоль мониторинга журналов собственных систем. Фронтенд и сервер работают на Node.js 22 или новее. Установка пакетов не требуется.

## Запуск на Windows

1. Клонируйте репозиторий или скачайте ZIP с GitHub.
2. Запустите `start.cmd`. Он поднимает сервер в фоне и открывает [главную страницу](http://127.0.0.1:4177/).
3. Если Node.js установлен в нестандартном месте, выполните `setup-runtime.cmd` в терминале, где доступна команда `node`, затем повторите запуск.

Для работы в терминале запустите `node server.mjs` и остановите его сочетанием Ctrl+C. Сервер слушает только `127.0.0.1`. Порт можно изменить через переменную окружения `ULTRASQUAD_PORT`. При запуске в фоне журналы самого сервера находятся в `data/`.

## Подключение журнала

Ваше приложение или сборщик должен добавлять по одному JSON-объекту на строку в `telemetry/events.jsonl`. Сервер читает новые строки примерно каждые 1,5 секунды и продолжает с сохранённой позиции после перезапуска.

```json
{"time":"2026-11-15T10:00:00+05:00","type":"auth_failed","source":"gateway","eventId":"sign-in-1001"}
{"time":"2026-11-15T10:02:00+05:00","type":"permission_changed","source":"admin-console","eventId":"permissions-651"}
```

Допустимые категории — `auth_failed`, `permission_changed`, `outbound_flagged` и `service_ok`. Значение `outbound_flagged` означает исходящую активность, которую уже отметила ваша система. В метке источника допустимы буквы, цифры, пробелы, точки, дефисы и подчёркивания. Максимальная длина — 40 символов. Назначайте событиям уникальные `eventId`, если их время, тип и источник могут совпасть.

На вкладке «Журнал» можно импортировать до 500 событий в одном JSON-файле до 256 КБ, искать по журналу и отмечать сигналы проверенными. Чтобы проверить фоновый приём, выполните `node sample-events.mjs`. Скрипт добавит шесть тестовых отказов входа в файл журнала.

## Агенты и прямой эфир

Можно создать до 100 агентов. Каждый проверяет указанный тип событий и, если задано, один источник. Сигнал появляется, когда счётчик за десять минут достигает порога агента. На вкладке «Прямой эфир» видны действия сервера, обработка событий и ответы моделей. График использует сохранённые счётчики.

В разделе «Модели» укажите ключ OpenRouter. Также можно передать ключ через переменную окружения `OPENROUTER_API_KEY`. Ключ хранится в памяти сервера. Каталог включает бесплатный маршрутизатор `openrouter/free` и бесплатные текстовые модели с нулевой ценой токенов. Сводка передаёт OpenRouter только категорию и агрегированные счётчики. Автоматические сводки включаются по агентам и ограничены 36 запросами за 24 часа для всего сервера. OpenRouter применяет собственные ограничения.

Конфигурация, счётчики, позиция чтения и последние события сохраняются в `data/state.json`. Фоновое видео и шрифты загружаются по сети. Для режима уменьшенного движения главная страница использует постер.
